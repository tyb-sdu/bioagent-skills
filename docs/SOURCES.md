# Research and installation sources

Installation commands are grounded in current maintainer documentation. Scientific papers explain what a tool does; they are not installation instructions. Each catalog JSON file contains the specific source links used for that software.

| Topic | Primary source | Why it matters here |
| --- | --- | --- |
| Agent Skill structure | [Agent Skills specification](https://agentskills.io/specification) | `SKILL.md` metadata, scripts, references, discovery |
| conda isolation and channels | [Conda channel guidance](https://docs.conda.io/projects/conda/en/stable/user-guide/tasks/manage-channels.html) | Per-command channels and dependency resolution |
| Bioconda platform limits | [Bioconda usage](https://bioconda.github.io/) | Linux/macOS support; Windows users need a suitable Linux environment for Bioconda packages |
| Windows Linux environment | [Microsoft WSL installation](https://learn.microsoft.com/en-us/windows/wsl/install) | Optional Windows path for Linux-only software |
| GPU compatibility | [NVIDIA CUDA driver matrix](https://docs.nvidia.com/datacenter/tesla/drivers/cuda-toolkit-driver-and-architecture-matrix.html) | Check driver/toolkit compatibility before choosing GPU packages |
| Containers on clusters | [Apptainer Docker/OCI support](https://apptainer.org/docs/user/latest/docker_and_oci.html) | OCI images can often be used in HPC environments |
| Model downloads | [Hugging Face download guide](https://huggingface.co/docs/huggingface_hub/guides/download) | Pin revisions, estimate size, and manage cache |
| Local model routing | [Ollama local API](https://docs.ollama.com/api/introduction), [chat endpoint](https://docs.ollama.com/api/chat), [structured outputs](https://docs.ollama.com/capabilities/structured-outputs), [local model listing](https://docs.ollama.com/api/tags) | Constrain the terminal entry point to a downloaded local model and validated catalog IDs |
| Python command packaging | [Python Packaging User Guide](https://packaging.python.org/en/latest/guides/writing-pyproject-toml/), [setuptools package data](https://setuptools.pypa.io/en/latest/userguide/datafiles.html) | Define console commands and include reviewed JSON recipes in the wheel |
| Pinned package builds | [Anaconda release API](https://api.anaconda.org/release/conda-forge/openmm/8.6.1), [PyPI MDAnalysis 2.10.0 metadata](https://pypi.org/pypi/MDAnalysis/2.10.0/json) | Check package files by platform/architecture and MDAnalysis Python ≥3.11; individual release URLs are recorded in the recipes |
| Structure repair and docking | [PDBFixer maintainer installation](https://github.com/openmm/pdbfixer/blob/master/README.md), [PDBFixer 1.12 builds](https://api.anaconda.org/release/conda-forge/pdbfixer/1.12), [Vina maintainer installation](https://autodock-vina.readthedocs.io/en/latest/installation.html), [Vina 1.2.7 builds](https://api.anaconda.org/release/conda-forge/vina/1.2.7), [Vina feedstock build script](https://github.com/conda-forge/vina-feedstock/blob/main/recipe/build.sh) | Distinguish PDBFixer noarch package from its platform-specific OpenMM dependency, and verify that the conda Vina build includes its CLI executable |
| Protein structure prediction | [AlphaFold 2 maintainer README](https://github.com/google-deepmind/alphafold/blob/main/README.md), [LocalColabFold installation](https://github.com/YoshitakaMo/localcolabfold/blob/main/README.md) | Distinguish the large AlphaFold 2 local database route from LocalColabFold's optional external MSA service and fully local setup |
| Molecular dynamics suites | [NAMD official downloads](https://www.ks.uiuc.edu/Development/Download/download.cgi?PackageName=NAMD), [NAMD license](https://www.ks.uiuc.edu/Research/namd/3.0.2/ug/node1.html), [AmberTools official download](https://ambermd.org/GetAmber.php) | Record user registration and license obligations for NAMD; distinguish free AmberTools from separately licensed Amber and note conda build feature limits |
| Electrostatics and protonation | [APBS installation](https://apbs.readthedocs.io/en/latest/getting/index.html), [APBS conda-forge recipe](https://github.com/conda-forge/apbs-feedstock/blob/main/recipe/meta.yaml), [PDB2PQR installation](https://pdb2pqr.readthedocs.io/en/latest/getting.html), [PDB2PQR 3.7.1 wheel](https://pypi.org/project/pdb2pqr/3.7.1/), [PROPKA installation](https://github.com/jensengroup/propka/blob/master/README.md), [PROPKA 3.5.1 wheel](https://pypi.org/project/propka/3.5.1/) | Keep local preparation separate from optional web services and registration; APBS's feedstock documents a nonzero `--version` exit code, requiring a targeted verification wrapper |
| Structure analysis and docking preparation | [FreeSASA installation](https://freesasa.github.io/), [FreeSASA-C 2.1.2 builds](https://api.anaconda.org/release/conda-forge/freesasa-c/2.1.2), [Meeko installation](https://github.com/forlilab/Meeko#installation), [Open Babel installation](https://openbabel.org/docs/Installation/install.html) | Distinguish command-line FreeSASA from separate Python bindings; treat Meeko as input preparation rather than a docking engine |
| Modeling and visualization | [Rosetta Commons software/download terms](https://rosettacommons.org/software/download/), [Rosetta build guide](https://docs.rosettacommons.org/docs/latest/build_documentation/Build-Documentation), [VMD overview and download](https://www.ks.uiuc.edu/Research/vmd/) | Handle Rosetta and PyRosetta licenses separately, and leave graphics-dependent VMD installation as guidance-only |
| Nucleic-acid computation | [NUPACK 4 getting started](https://docs.nupack.org/start/), [oxDNA source-build guide](https://github.com/lorenzo-rovigatti/oxDNA/blob/master/docs/source/install.md) | NUPACK requires user acceptance of its terms; oxDNA backends and optional bindings require build-time choices |
| Cryo-EM processing | [RELION installation](https://relion.readthedocs.io/en/release-5.0/Installation.html), [CryoSPARC setup and licensing](https://guide.cryosparc.com/setup-configuration-and-management/how-to-download-install-and-configure), [ModelAngelo installation](https://github.com/3dem/model-angelo) | Keep complex source builds, external dependencies, license IDs and large model weights out of one-click execution |
| Visualization and GPU docking | [ChimeraX licensing](https://www.cgl.ucsf.edu/chimerax/docs/licensing.html), [PyMOL Open Source feedstock](https://github.com/conda-forge/pymol-open-source-feedstock/blob/main/README.md), [AutoDock-GPU build](https://github.com/ccsb-scripps/autodock-gpu) | Separate open-source and licensed GUI releases, and select GPU toolchains according to local hardware |
| Foundry protein models | [RoseTTAFold3 installation](https://github.com/RosettaCommons/foundry/blob/production/models/rf3/README.md), [RFdiffusion3 installation](https://github.com/RosettaCommons/foundry/blob/production/models/rfd3/docs/tutorials/RFdiffusion3_installation_tutorial.md), [Rosetta Commons software terms](https://rosettacommons.org/software/download/) | Distinguish newer RF3/RFD3 routes from older models; checkpoint downloads and accelerator choice remain explicit user decisions |
| Isolated chemistry and trajectory packages | [Open Babel conda-forge feedstock](https://github.com/conda-forge/openbabel-feedstock/blob/main/README.md), [Meeko installation](https://meeko.readthedocs.io/en/develop/installation.html), [MDTraj installation](https://mdtraj.readthedocs.io/en/stable/installation.html), [ParmEd repository](https://github.com/ParmEd/ParmEd) | Pinned builds and smoke tests enable a conservative automatic route while format conversions and scientific interpretation remain separate |
| Crystallography, interaction fingerprints and force-field extensions | [Gemmi installation](https://gemmi.readthedocs.io/en/stable/install.html), [Gemmi conda package](https://anaconda.org/conda-forge/gemmi/files?version=0.7.5), [ProLIF installation](https://prolif-water.readthedocs.io/en/latest/source/installation.html), [ProLIF conda package](https://anaconda.org/conda-forge/prolif/files?version=2.1.0), [OpenMMForceFields installation](https://github.com/openmm/openmmforcefields/blob/main/README.md), [OpenMMForceFields conda package](https://anaconda.org/conda-forge/openmmforcefields/files?version=0.16.0) | Keep basic installation and import verification separate from experimental interaction analysis or force-field validation; optional force-field backends can have separate dependencies or licensing |

These references support tool descriptions and task matching; installation routes come from the linked maintainer pages.
